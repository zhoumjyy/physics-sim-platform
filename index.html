📖 接入指南 — 如何添加新的物理模拟器 ▾

📐 模拟器接入规范

您可以使用 AI 生成任意物理模拟 HTML 文件，并轻松接入本平台。

📁 文件格式要求

  • 每个模拟器必须是 独立的 HTML 文件（含 CSS / JavaScript）。
  • 建议采用 毛玻璃质感 设计风格以保持视觉统一，但非强制。
  • 模拟器应 自适应 容器尺寸，或在 iframe 中能完整显示。
  • 所有资源请使用 内联或 CDN，避免相对路径引用失败。

🔌 接入步骤

  1. 将模拟器 HTML 文件放入 simulations/ 目录。
  2. 在 sims.json 清单的对应分类中添加一条配置（或直接打开右上角 🛠 工作台 可视化编辑）。
{ id: 'your-sim-id', name: '模拟器名称', description: '简短描述', icon: '🚀', src: 'simulations/your-sim.html' }

✅ 完整示例（在力学分类下添加）

// sims.json：数组即分类，sims 即模拟器 [ { "id": "mechanics", "name": "🔬 力学", "sims": [ { "id": "displacement-micro-element", "name": "微元法 · 位移公式推导", "description": "匀变速直线运动 · 以直代曲", "icon": "📐", "src": "simulations/displacement-micro-element.html" }, { "id": "projectile", "name": "平抛运动", "description": "速度矢量 · 轨迹", "icon": "🎯", "src": "simulations/projectile.html" }, { "id": "free-fall", "name": "自由落体", "description": "重力加速度演示", "icon": "📐", "src": "" } ] } // 更多分类... ]

🎨 设计建议

  • 推荐使用与本平台一致的 深色毛玻璃 风格。
  • 画布尺寸建议 820×620 或自适应。
  • 交互控件请使用 大圆角 + 柔和阴影 以提升质感。
  • 可参考已集成的 平抛运动模拟器 代码风格。

💡 提示：编辑 sims.json 并刷新即可增删模拟器；或用右上角 🛠 工作台 可视化操作，无需改代码。

🔐 管理员登录

输入管理员密码后，可使用「🛠 工作台」编辑、增删模拟器。

☁️ 云端同步状态

读取云端同步信息中…

本平台为纯静态站点，浏览器页面自身无法把修改直接写回云端。真正的同步由 AI 代理 完成：

  • 保存并上传：关闭页面前会询问"是否保留修改"；您也可直接对我说"帮我同步到云端"，我便把本地部署到公网（同一链接复用）。
  • 开工加载云端：我每次开工时会先拉取公网上的 sims.json / sync-meta.json 与本地比对，确保不覆盖云端最新内容。
  • 学生参数：模拟器里调的参数会自动存本机浏览器，并可"导出 / 导入"JSON 随身带走、收集后作为预设重新发布。
